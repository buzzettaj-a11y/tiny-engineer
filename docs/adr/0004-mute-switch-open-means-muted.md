# An open mute switch means muted

Joe uses a maintained I/O rocker switch for mute, wired from GP7 to ground. In switch mode, closed ("I") means listening and open ("O") means muted, so a broken or unplugged wire fails safe to muted. Because a robot with nothing on GP7 would then be muted forever, switch mode is a setting that is off by default; the default stays the original momentary button that toggles mute on each press.
